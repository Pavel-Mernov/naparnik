# llm — локальная языковая модель

**Владелец:** роль 2 (ML / LLM).

Ollama с вшитой моделью **qwen3:4b** (открытые веса, Apache 2.0). Работает на процессоре. Ей пользуется только `ml`.
Модель скачивается в образ при сборке, после запуска интернет не нужен; `entrypoint.sh` прогревает модель.

| Модель | RAM | Когда |
|---|---|---|
| `qwen3:4b` | ~3,5 ГБ | по умолчанию |
| `qwen3:8b` | ~6 ГБ | ноутбук с 16+ ГБ — лучше русский и JSON |
| `bge-m3` | ~1,2 ГБ | эмбеддинги для поиска (опционально) |

**Mac:** нативная Ollama в разы быстрее Docker — `brew install ollama && ollama pull qwen3:4b && ollama serve`,
в `.env`: `OLLAMA_URL=http://host.docker.internal:11434`.

Модель выбираем замером (`ml/eval`), а не на глаз: берём самую лёгкую, которая проходит пороги.
