## Сервисы

| Сервис | Папка | Отвечает за | Не делает |
|---|---|---|---|
| `frontend` | `frontend/` | Экраны, анимации, Cmd+K, режим моков | Не ходит в ml напрямую |
| `backend` | `backend/` | Вход, роли, БД, задачи, напоминания, карточки, доска ментора, **выполнение действий**, отправка в Slack | Не генерирует тексты |
| `worker` | `backend/app/worker.py` | Раз в 15 с отправляет созревшие напоминания (`FOR UPDATE SKIP LOCKED` на Postgres) | — |
| `ml` | `ml/` | Агент: роутер намерений, RAG с цитатами, черновики сообщений, самоотчёт, глоссарий; проверка ответов LLM | Не пишет в БД, ничего не отправляет |
| `llm` | `llm/` | Локальная модель с открытыми весами (Ollama) | — |

## Агент: гибрид, а не свободный ReAct

Малая локальная модель на CPU в свободном цикле «думай-действуй» зацикливается и выдумывает аргументы. Поэтому:

1. **Правила до LLM.** «Напомни через 10 минут…», «добавь задачу…», «запомни, что…», «что такое X» — разбираются
   регулярками и словарём, LLM не вызывается.
2. **Роутер намерений.** Если правила не сработали — один вызов LLM со строгим JSON
   (`qa | task | reminder | remember | smalltalk`). Нет LLM — по умолчанию `qa`.
3. **Обработчик на каждое намерение** — детерминированный. Возвращает текст и *предложенные* действия.
4. **Backend выполняет** только безопасные действия (`create_task`, `set_reminder`, `remember`) от имени
   пользователя из токена. **Отправки сообщений у агента нет вообще** — только черновик и кнопка у человека.
   Это закрывает и ошибки модели, и prompt injection из текстов Notion/Slack.

## RAG

- Источники: `ml/data/kb/*.md` (демо-вики) → позже импорт Notion в тот же формат.
- Чанки по заголовкам Markdown, в чанке хранится путь заголовков.
- Поиск: лексический BM25 (работает всегда, без модели) + эмбеддинги `bge-m3` через Ollama, если доступны;
  объединение рангов (RRF). Следующий шаг — перенести индекс в pgvector (`kb_chunks`, HNSW + `tsvector russian`).
- Против выдумок: фрагменты нумеруются, модель обязана ставить `[n]`; ссылки на несуществующие фрагменты
  вырезаются; ответ без ссылок → «не нашёл в базе, спроси у <кто>»; лучший балл ниже порога → LLM не вызывается.

## Модели

| Модель | RAM | Когда |
|---|---|---|
| `qwen3:4b` | ~3,5 ГБ | **по умолчанию**, ноутбук 8–16 ГБ |
| `qwen3:8b` | ~6 ГБ | если 16+ ГБ — заметно лучше русский и JSON |
| `bge-m3` | ~1,2 ГБ | эмбеддинги (опционально, без них — BM25) |

Thinking выключен (`think: false`), модель прогревается при старте. `qwen3:1.7b` из прошлого проекта для
роутинга слабовата — проверить замером (`ml/eval`).

## Приватность

- Карточку коллеги заполняет только он сам (`consent_at`), полей про характер нет.
- Агент не делает выводов о людях из их сообщений.
- Память стажёра видит только стажёр; ментор видит прогресс и вопросы, но не память и не анонимные авторства.
- Данные не уходят наружу: модель локальная. Внешний API можно подключить переменной, тогда в UI — бейдж
  «данные уходят наружу».
- Тексты из Notion/Slack — это данные, не инструкции: оборачиваются в `<document>`, write-действия из QA-ветки
  недоступны.
