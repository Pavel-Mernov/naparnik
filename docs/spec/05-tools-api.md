# 05. Инструменты агента и имитации сервисов

PDF стр. 10: в Авито уже есть данные сотрудников, авторизация, роли, ИИ-агенты с промптами и **MCP**; для прототипа можно имитировать API и оформлять действия через MCP. Стр. 11: действие выполнено, если сервис или имитация вернули результат, а помощник его отобразил и сохранил.

## Архитектура вызова

```
Сайт / Telegram ──► API (Go) ──► Агент (Python) ──► LLM (внешний API, из .env)
                       │               │
                       │               └── MCP-клиент ──► MCP-серверы-адаптеры ──► имитации сервисов
                       └── права, сессии, квитанции, уведомления
```

- Агент вызывает инструменты **только через MCP**. Каждый корпоративный сервис — отдельный MCP-адаптер. В Авито меняется адаптер, агент и сценарии остаются.
- `user_id` и роль передаются адаптеру из сессии, а не из аргументов модели.
- Каждый вызов пишется в журнал событий (clickstream): кто, что, когда, результат. Отсюда метрики (00) и Grafana.

## Ответ инструмента

Единый формат:

```json
{ "ok": true, "data": { }, "receipt": { "id": "ABS-1042", "status": "pending", "created_at": "..." } }
{ "ok": false, "error": { "code": "forbidden | not_found | validation | unavailable", "message": "человеческое объяснение", "who_can": "Ирина Соколова" } }
```

`receipt` есть у всех инструментов с подтверждением; API сохраняет её и показывает в чате, ленте и «Моих заявках».

## Справочник кодов причин отказа

| Код | Смысл для стажёра |
|---|---|
| `DATE_CONFLICT` | В эту дату важная встреча или релиз команды — предложим другую |
| `TOO_LATE` | Подано позже срока по регламенту |
| `NOT_NEEDED_YET` | Доступ понадобится позже, на другом этапе |
| `NEED_INFO` | Не хватает данных — уточни и подай снова |
| `OTHER` | Другое — с обязательным комментарием |

## Имитации сервисов

Каждая имитация — отдельный модуль с собственным хранилищем (PostgreSQL) и REST API в формате, близком к оригиналу (Jira REST, Confluence REST). Данные — синтетические фикстуры из 02. Режим `INTEGRATIONS_MODE=mock` по умолчанию; переключение на реальный сервис — замена адаптера.
