## Чек-лист

Основа маршрута — чек-лист стажёра Авито:
- вкладка **«Материалы для всех»** — общие шаги стажёра и наставника (неделя 1 → экватор → выпускной);
- вкладка **«Чек-лист Backend»** — шаги Backend-стажёра по периодам (1 неделя, 2 неделя, 1–3 месяц, после 3 месяцев).

Для Frontend и Аналитики делаем короткие синтетические чек-листы по образцу (5–8 шагов) с пометкой «демо».

Каждый шаг в данных: `id`, `title`, `period` (неделя/месяц), `owner` (стажёр или наставник), `type` (доступ / изучить / встреча / настроить), `due_date` (считается от даты начала стажировки), `status` (`todo`, `in_progress`, `done`, `blocked`), `source` (вкладка чек-листа).
