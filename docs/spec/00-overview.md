# 00. Обзор: что делаем и как это закрывает кейс

> Спецификация поведения AI-buddy (SDD). Код пишется по этим документам; если код и спецификация расходятся — правим спецификацию осознанно, а не код молча.
> Источник требований — кейс Авито «AI-buddy: ИИ-наставник для стажёров» (Hack&Change 2026), далее «PDF». Концепция команды — [../ideas/IDEA-AND-FLOWS.md](../ideas/IDEA-AND-FLOWS.md).

## Концепция в одной фразе

**AI-buddy ведёт стажёра по стажировке, а прогресс видят все. Каждый вопрос стажёра превращается в знание команды.**

## Каналы

| Канал | Роль | Что там |
|---|---|---|
| **Сайт** | Рабочее место | Маршрут по чек-листу, люди и инструменты отдела, чат с агентом, заявки, кабинеты наставника и руководителя |
| **Telegram-бот** | Информер + быстрые действия | Сводка утром, горящие сроки, статусы заявок, ответы наставника, жаргон команды, выжимки встреч; короткие вопросы и отгул |

Оба канала работают с одним агентом и одними данными. Telegram — сменный канал: в проде Авито он заменяется корпоративным мессенджером без изменения агента.

## Метрики пользы (постановка 06)

| Метрика | Как считаем в прототипе | Связь с кейсом |
|---|---|---|
| Доля вопросов, закрытых без наставника | ответ из базы + «помогло» / все вопросы | Рутинные обращения (стр. 5) |
| Повторные вопросы к наставнику | вопросы, ответ на которые уже был в базе на момент эскалации | Рост базы знаний |
| Время от запроса до результата действия | создание черновика → квитанция сервиса | «Путь от запроса до результата» (формат сдачи 04) |
| Пункты чек-листа в срок | выполнено до дедлайна / все с дедлайном | Этапы адаптации (постановка 04) |
| Оценка экономии часов наставника | (закрытые без наставника вопросы × 10 мин) + (организационные действия × 5 мин) | 40–48 ч за 6 мес (стр. 5) |

Проверка эффекта на стажёрах: A/B по когортам (одна когорта с AI-buddy, одна без) или до/после на одной команде; в прототипе — на синтетической когорте с журналом событий.

## Модель

Внешний API, провайдер и модель задаются в `.env` (`LLM_PROVIDER`, `LLM_MODEL`, ключ). PDF стр. 9: указываем сервис, модель, переменную окружения, пример конфигурации без секретов.
