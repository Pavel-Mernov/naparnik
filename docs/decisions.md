# Журнал решений

Формат: решение — почему — что отвергли. Новое решение добавляет тот, кто его принял, и пишет в чат команды.

| # | Решение | Почему | Отвергли |
|---|---|---|---|
| 1 | Главная фича — общение с коллегами по их собственной карточке + вопросы с источниками; остальное вторично | Это единственное, чего нет у Donut/Glean/Moveworks; 9 равных фич = «ещё один копилот» | Делать все 9 функций одинаково |
| 2 | Карточку заполняет сам коллега; полей «не любит / причуды» нет | 152-ФЗ, согласие, этика; жюри спросит «откуда данные» | Досье, заполняемое стажёром или ИИ |
| 3 | Агент предлагает действия, backend выполняет; отправка сообщений — только по клику человека | Малая модель ошибается; защита от prompt injection | Свободный ReAct-агент с инструментом send_message |
| 4 | Ответ только с цитатами или «не нашёл — спроси у …» | Одна выдумка убивает доверие | Свободная генерация без источников |
| 5 | Локальная модель с открытыми весами, без LLM всё работает на шаблонах | Корпоративные данные не уходят наружу; демо не падает | Платные API по умолчанию |
| 6 | Веб «Доска дня» + Slack как канал доставки | Красивый веб нужен для демо и ментора; Slack — чтобы стажёр не бросил | Только чат-бот / только веб |
| 7 | Tailwind v4 + motion + cmdk + dnd-kit вместо MUI | MUI узнаётся мгновенно и мешает анимациям | MUI, Mantine |
| 8 | Стек backend как в Smart Credit: FastAPI + SQLModel + Postgres, uv | Команда его знает | — |
| 9 | Напоминания — таблица + worker-цикл, без Celery/Redis | Меньше сервисов, переживает рестарт | Celery, arq |
| 10 | Интеграции — адаптеры с демо-режимом по умолчанию | Демо без единого токена, страховка от Wi-Fi на площадке | Только живые интеграции |
| 11 | Схема БД пока через `create_all`; Alembic — первая задача backend после фиксации моделей | Модели ещё меняются в первые часы | Миграции с первой минуты |
| 12 | RAG-индекс пока в памяти ml (BM25 + опц. эмбеддинги), позже — pgvector | Запускается за минуты, не блокирует команду | Сразу Qdrant/Chroma — лишний сервис |
