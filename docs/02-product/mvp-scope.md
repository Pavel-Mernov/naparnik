# MVP: что показываем жюри

## Must-have — работает вживую

| Фича | Экран / канал | Готово, когда |
|---|---|---|
| **Утренний бриф «Сегодня»** | Веб: таймлайн дня; Slack: одно сообщение в 9:00 | Встречи, задачи, напоминания и термин дня собираются на экране; спикерская встреча подсвечена, у встречи есть «как подготовиться» |
| **Визитки коллег + «Как написать?»** | Веб: «Люди» | Карточку заполняет сам коллега; черновик учитывает ты/Вы, канал, часы ответа; предупреждает «после 19:00 не пишите»; отправка в Slack только по клику |
| **Вопрос по компании с источниками** | Веб: Cmd+K; Slack DM | Ответ с `[1] [2]` и ссылками; если не нашёл — «не нашёл, спроси у <кто>»; без LLM — показывает найденные фрагменты |
| **Анонимный «глупый вопрос»** | Cmd+K, переключатель | Вопрос без имени виден ментору в разделе «О чём спрашивают» |
| **Задачи и напоминания** | «Сегодня», Cmd+K («напомни через минуту…») | Напоминание срабатывает через worker и приходит в веб (и Slack, если подключён) |
| **Доска ментора** | Веб: «Ментор» | Видно, кто застрял > 2 дней, давно ли был контакт, топ вопросов и пробелы в вики |

## Wow — 1–2 штуки, доведённые до блеска

- День, который «собирается сам» на глазах (анимация брифа).
- Переворот визитки → черновик → сообщение реально приходит в Slack на проекторе.

## Второй приоритет (если останется время)

- Пятничный самоотчёт → черновик к 1:1 (каркас уже есть).
- «Что я о тебе помню» с удалением (каркас уже есть).
- План онбординга по неделям (каркас уже есть).
- Импорт страниц Notion в базу знаний кнопкой.
- Календарь из ICS.

## Вне MVP

Профили «что не любит», вывод характеристик из переписки, свой таск-трекер, рейтинги, транскрибация, web push,
двусторонний Notion, SSO (на демо — заглушка, вслух: «уважаем права доступа»).

## Демо-сценарий (4 минуты) — «Первый вторник стажёра Маши»

| Время | Что показываем |
|---|---|
| 0:00–0:30 | Боль одной фразой: «В первую неделю стажёр боится спросить глупость и написать не тому и не так» |
| 0:30–1:10 | 9:00, Маша открывает «Сегодня» — день собирается на глазах; спикерская встреча в 12:00 с подсказкой, термин дня |
| 1:10–2:10 | **Кульминация.** Нужен доступ к Grafana от Ивана Петровича. Переворот визитки: «на Вы, кратко, только Slack, после 19 не писать» → «Как написать?» → черновик → «Отправить» → сообщение приходит в Slack на экране |
| 2:10–2:50 | Cmd+K: «как оформить командировку?» → ответ со ссылками. Анонимно: «что такое ПСИ?» Перетащить задачу на таймлайн |
| 2:50–3:30 | Вход за Ольгу (ментор): «Маша застряла на доступах 2 дня», «о чём спрашивают», пробелы в вики |
| 3:30–4:00 | Метрики-методика и финальная фраза-позиционирование |

Правила демо: данные засижены, без «Lorem»; один говорит, второй управляет ноутбуком; видео-бэкап записан
заранее; если LLM тормозит — `OLLAMA_URL=` и всё на шаблонах.
