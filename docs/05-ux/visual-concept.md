# Визуальная концепция — «Доска дня»

## Почему не «ИИ-шный» интерфейс

Узнаваемые признаки, которых у нас нет: чат как главный экран, фиолетово-синие градиенты, иконки ✨, стекло и
свечение на тёмном фоне, shadcn по умолчанию (Inter, серые рамки, сетка одинаковых карточек), «печатная машинка»,
аватар-«орб», фраза «Я ваш ИИ-ассистент». ИИ у нас — **механика**, а не персонаж.

## Метафора

Рабочий стол стажёра: вертикальная линейка дня 9:00–19:00 с движущейся красной линией «сейчас», на ней лежат
физичные объекты — карточки встреч, стикеры-задачи, визитки людей. Слева — стопка визиток коллег, справа —
стикеры дня. Метафора объясняется за 5 секунд и полезна каждый день, а не только в первую неделю (в отличие от
«карты-квеста»).

## Токены

| Токен | Светлая | Тёмная |
|---|---|---|
| Фон (бумага) | `#F4F1EA` | `#16150F` |
| Текст (чернила) | `#1B1A17` | `#EDE9DF` |
| Акцент (один, редко) | `#FF5A36` томатный | `#FF6B4A` |
| Стикер | `#FFE98A` | `#5A4E1E` |

Шрифты: **Unbounded** (заголовки), **Onest** (текст), **JetBrains Mono** (время, мета). Тени — мягкие «бумажные»,
радиусы небольшие, стикеры повёрнуты на 1–2°.

## Анимации, которые несут смысл

| Момент | Что двигается | Смысл |
|---|---|---|
| Утренний бриф | Карточки встреч «падают» в слоты по очереди (stagger 60–80 мс) | Ассистент разложил день за тебя |
| Визитка | 3D-переворот: лицо — имя и «ты/Вы», оборот — канал, часы, «Как написать?» | Как обращаться — главное, остальное по запросу |
| Аватар → визитка | Shared layout (`layoutId`) | Не теряется связь между встречей и человеком |
| Задача сделана | Стикер сминается и улетает в «сделано», шкала недели растёт | Прогресс без конфетти |
| Cmd+K | Палитра раскрывается из центра, ответ появляется **готовой карточкой** | Ответ — документ со ссылками, а не болтовня |
| Перетаскивание | Задача на таймлайн, соседние карточки раздвигаются; конфликт краснеет до отпускания | Планирование руками |

Правила: только `transform` и `opacity`, 150–300 мс, одна большая анимация на экран, `prefers-reduced-motion`
уважается, проверить на ноутбуке с проектором.

## Библиотеки

`motion` (бывший framer-motion), `cmdk`, `@dnd-kit/core`, `sonner`, Tailwind CSS v4 + собственные токены.
Не берём: MUI (узнаётся мгновенно), three.js (тяжело и не про смысл), Lottie/Rive — только если есть человек,
который умеет.

## Где живёт ИИ

Визитка («Как написать?»), подсказка при отправке («после 19:00 — отправить завтра в 9:30?»), Cmd+K (вопросы с
источниками), напоминания с контекстом («встреча со спикером — вот 2 вопроса»), пятничный черновик к 1:1.
Чат — вторичен и в демо показывается не дольше 10 секунд.
