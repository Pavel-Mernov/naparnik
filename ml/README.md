# ml — агент, база знаний, черновики сообщений

**Владелец:** роль 2 (ML / LLM). Демо-вики и глоссарий в `data/` — роль 5 (продукт).

Stateless-сервис: получает контекст от backend, возвращает текст, цитаты и **предложенные** действия.
В БД не пишет, ничего не отправляет. Без LLM (`OLLAMA_URL=` пусто) каждый эндпоинт отвечает правилами и шаблонами.
Устройство агента — [docs/architecture.md](../docs/architecture.md).

## Структура (план)

```
ml/
├── service/
│   ├── main.py      FastAPI: /health, /v1/respond, /v1/draft, /v1/kb/search, /v1/glossary, /v1/weekly
│   ├── llm.py       клиент Ollama (+ OpenAI-совместимый endpoint по env), таймауты, прогрев
│   ├── agent.py     правила до LLM (напомни / добавь задачу / запомни / что такое) → роутер → обработчики
│   ├── kb.py        Markdown → чанки по заголовкам → BM25 + эмбеддинги (bge-m3) → RRF
│   └── draft.py     черновик коллеге по его карточке: ты/Вы, канал, часы ответа; проверка ответа модели
├── data/
│   ├── kb/*.md      демо-вики компании (строка «Источник: …» в каждом файле)
│   └── glossary.yaml словарь жаргона
├── eval/            замеры: точность роутера, RAG hit@3, доля ответов, прошедших проверку
└── tests/           pytest без LLM
```

## Правила качества

- Ответ на вопрос — только со ссылками `[n]` на найденные фрагменты; нет ссылок → «не нашёл, спроси у …».
- Черновик на «Вы» не должен содержать «ты»-форм — проверяется кодом.
- Никаких выводов о характере коллег.

## Запуск

```bash
uv sync
OLLAMA_URL=http://localhost:11434 uv run uvicorn service.main:app --reload --port 8001
```
